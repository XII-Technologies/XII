# Render pipeline properties

xiiRenderPipelineInterfacePass::Name;Interface Name;Name exposed on every subgraph instance. An input and an output can share a name to pass a resource through the pipeline.
xiiRenderPipelineInterfacePass::Input;External Input;Inputs supply resources to the graph through Value. Connect an internal resource to Default to use it when the including pipeline leaves this input unconnected. Outputs publish the resource connected to Value.
xiiRenderPipelineInterfacePass::ResourceType;Resource Type;Resource kind accepted by this interface. The including pipeline must connect a compatible resource.
xiiRenderPipelineInterfacePass::Format;Texture Format;Optional texture format contract. Unknown accepts the connected resource's format.
xiiRenderPipelineInterfacePass::DataType;Snapshot Type;Reflected frame-data snapshot type accepted by this interface.
xiiRenderPipelineSubgraphPass::Resource;Render Pipeline;Reusable pipeline definition. Its declared inputs and outputs appear as pins on this node. Parent connections override internal input defaults for this instance.

xiiCreateTexturePass::Texture;Texture;Configure the texture to create through this output pin. Connect it to a writer such as Clear Color before reading it.
xiiRenderPipelineTextureOutputPin::Format;Format;Texture format. Create Texture uses RGBA16 Float when Unknown is selected.
xiiRenderPipelineTextureOutputPin::Requirements;Texture Properties;Create Texture allocates from these pin properties. Zero width or height follows the view's render resolution. Undefined dimension uses 2D and zero samples uses one sample.

xiiRenderPipelinePinConfiguration::DisplayName;Pin Label;Optional label for this pin in the graph. Leave empty to use its native name. Click a pin to edit its connection settings.
xiiRenderPipelinePinConfiguration::RequiredFormat;Required Texture Format;Optional validation of the connected texture. Unknown accepts its native format. This does not choose or change the texture allocation. Set the producing pass's Format to do that.
xiiRenderPipelinePinConfiguration::Requirements;Connection Requirements;Optional checks on the connected resource. Zero or Undefined keeps the native contract. These requirements validate a connection and do not allocate or resize resources.
xiiRenderPipelinePinConstraints::Dimension;Texture Dimension;Optional required texture dimension. Undefined keeps the native requirement.
xiiRenderPipelinePinConstraints::Samples;Sample Count;Required texture sample count. Zero keeps the native requirement. Create Texture uses one sample when zero is selected.
xiiRenderPipelinePinConstraints::Width;Width;Texture width in pixels. Zero leaves the extent unconstrained. Create Texture uses the view's width when zero is selected.
xiiRenderPipelinePinConstraints::Height;Height;Texture height in pixels. Zero leaves the extent unconstrained. Create Texture uses the view's height when zero is selected.
xiiRenderPipelinePinConstraints::RequiredBindFlags;Required Bindings;Bindings the connected texture or buffer must support. An empty selection adds no requirements to the native contract.
