# XII

<p align="center">
  <img src="Documentation/XII-Logo.png" alt="XII Engine logo" width="128">
</p>

XII is a modular, multi-platform engine for real-time simulation and interactive applications. Built in C++23, it combines rendering, simulation, resource management, and native development tools in a unified architecture.

Its modular design lets applications use the complete engine or integrate individual components through dynamically linked libraries, providing flexibility for specialized tools and simulation workloads.

For further details, visit the official website at [www.xiitechnologies.com](https://www.xiitechnologies.com).
